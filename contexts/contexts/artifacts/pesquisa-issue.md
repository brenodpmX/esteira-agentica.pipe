# Pesquisa

## Utilidade

Toda solicitação de pesquisa na internet por documentação, especificação, padrões e quaisquer outros dados necessários para embasar o desenvolvimento deve ser feito com este template.

- Outras

---

## Resultado esperado

<Descreva quais documentos ou informações espera receber>

---

## Critério de conclusão

A pesquisa será considerada concluída quando:

- a documentação for criada ou atualizada em `doc/biblioteca`;
- todas as referências relevantes estiverem documentadas;
- a issue de origem possuir todas as informações necessárias para prosseguir.
